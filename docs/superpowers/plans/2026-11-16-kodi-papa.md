# Kodi de Papá — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Kodi repository (GitHub Pages) plus a `script.papa.inicio` addon that turns a Kodi 21 Omega box into an Apple‑TV‑style Arctic Fuse 3 home with Películas · Series · Novedades · Deportes · Favoritos built from Palantir and BlackGhost, IMDb ratings, and Spain‑only Spanish auto‑trailers.

**Architecture:** Pure‑Python logic (label matching, preset JSON generation, trailer choice, report building, repo build) lives in small modules that are unit‑tested with Kodistubs. Thin Kodi glue (`kodi_setup.py`, `default.py`, `service.py`) calls JSON‑RPC and builtins. The skin is configured through Arctic Fuse 3's own mechanism: `RunScript(script.skinvariables,copy_menufolder=…,skin=skin.arctic.fuse.3,force=True)` plus `Skin.SetString` builtins copied from `shortcuts/builtins/skinvariables-setupwizard-preset.json`.

**Tech Stack:** Python 3 (Kodi Omega ships 3.11, so syntax stays ≤3.8), Kodi JSON‑RPC, pytest + Kodistubs 21, stdlib only (urllib, zipfile, hashlib, json, re, unicodedata).

**Spec:** `docs/superpowers/specs/2026-11-16-kodi-papa-design.md`

## Global Constraints

- Skin id `skin.arctic.fuse.3`; SkinFolder for skinvariables = `skin.arctic.fuse.3`.
- Hubs: 1101 Películas (film.png, slot 01), 1102 Series (tv.png, 02), 1103 Novedades (recentlyadded.png, 03), 1104 Deportes (trophy.png, 04), 1109 Favoritos (heart.png, 09). 1106/1107/1108 disabled (`"disabled": "True"`).
- Hub item keys exactly: `label, icon, path, target, window, slot, disabled`. Widget/submenu keys: `label, icon, path, target` (+ optional `widget_style`).
- Icons live at `special://skin/extras/icons/<name>.png`.
- Ratings: `Skin.SetString(CustomRating.Movies.Item01,IMDb)`, `Skin.SetString(CustomRating.TVShows.Item01,IMDb)`, `Skin.Reset(TMDbHelper.DisableRatings)`.
- TMDb Helper: setting `language` = `20` (es‑ES); `omdb_apikey` = user key.
- Trailers: only TMDb videos with `site == "YouTube"`, `type == "Trailer"`, `iso_639_1 == "es"`, `iso_3166_1 == "ES"`. None found → play nothing.
- Never write the AllDebrid key, BlackGhost code, or any setting *value* of other addons into reports or the repo.
- Pages base URL: `https://bruivert.github.io/Kodi/`; our datadir `…/zips/`; jurialmunkey Omega datadir `https://raw.githubusercontent.com/jurialmunkey/repository.jurialmunkey/master/omega/zips/` with `minversion="20.9.1"`.
- All user‑visible text in Spanish (Spain).

## Review Focus

1. Palantir/BlackGhost labels with Kodi markup (`[COLOR gold][B]Fútbol[/B][/COLOR]`), emojis or accents → still match.
2. "Fútbol Americano" / "NFL" must land in NFL, never in Fútbol; "F1" must not match inside unrelated words.
3. A category missing in the addon → that row/submenu entry is simply omitted (no empty rows, no crash); a hub with zero rows still shows Favoritos/other hubs.
4. Trailer list with only es‑MX / es‑419 / en trailers → `None` (no Latin or English trailer ever).
5. Real playback (fullscreen movie from Palantir) must never be stopped by the trailer service.

### Task 1: Label matching and discovery (`discover.py`)

**Files:** Create `src/script.papa.inicio/resources/lib/discover.py`, `src/script.papa.inicio/resources/__init__.py`, `src/script.papa.inicio/resources/lib/__init__.py`, `tests/conftest.py`, `tests/test_discover.py`

**Interfaces — Produces:**
- `normalize(label: str) -> str` — strips `[TAG]`/`[TAG …]` markup, accents, case, non‑alphanumerics → single spaces.
- `matches(label: str, keywords: list, exclude: list = ()) -> bool` — word‑boundary match on normalized text.
- `PALANTIR_ROOT`, `PELICULAS`, `SERIES`, `DEPORTES_ROOT`, `DEPORTES` (ordered: `agenda, nfl, futbol, baloncesto, padel, f1, motogp, ufc`) — dicts `key -> {"keywords": [...], "exclude": [...], "label": str}`.
- `classify(entries: list, catalog: dict) -> dict` — `{key: {"label", "path"}}`; each entry used at most once; catalog order is priority.
- `discover_palantir(list_dir, find_addon, ask) -> dict` and `discover_blackghost(list_dir, find_addon, ask) -> dict` where `list_dir(path) -> [{"label","file","filetype"}]`, `find_addon(keywords) -> addon_id|None`, `ask(title, labels) -> int` (‑1 = skip). Missing required categories (`peliculas`/`series` folders, `deportes` folder) trigger `ask`; missing optional ones are omitted.

- [ ] Tests: normalize markup/accents; NFL vs Fútbol; `f1` word boundary; classify uses each entry once; discover with fake trees (Palantir: Películas/Series with Estrenos, Populares, Mejor valoradas, Géneros, En emisión, Novedades; BlackGhost: Deportes with Agenda, Fútbol, Fútbol Americano, NBA, Pádel, Fórmula 1, MotoGP, UFC); unmatched required folder → `ask` called and its choice used; `ask` returns ‑1 → category absent.
- [ ] Run: `python3 -m pytest tests/test_discover.py -q` → FAIL, implement, → PASS. Commit.
